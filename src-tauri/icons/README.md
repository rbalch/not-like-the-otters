# Icon set

Generated by `tauri icon`, from the plated otter mark — the plated intermediate is not
tracked in this repo (derivable from the tracked master plus the command below).

```
source  assets/brand/otter-icon-1024.png
crop    728x728 at offset (164, 124)      # mark bbox 288..768 x 212..765, 12% margin/side
scale   to 1024x1024
plate   #f3f2f2  (Classical --color-bg)
command npm run tauri -- icon <plated-source.png>
```

**The Android and iOS sets are deliberately pruned.** This app is desktop-only —
packaging, distribution and mobile are out of scope (see `AGENTS.md`). `tauri icon`
generates `android/` and `ios/` by default; both were deleted after generation to keep
this directory to what the desktop build actually uses.

Re-running `tauri icon` recreates `android/` and `ios/`. **Delete them again** — do not
commit them.

Kept: the five paths in `tauri.conf.json`'s `bundle.icon` array
(`32x32.png`, `128x128.png`, `128x128@2x.png`, `icon.icns`, `icon.ico`), plus
`icon.png`, `64x64.png`, and the Windows `Square*Logo.png` / `StoreLogo.png` set.
